# 项目与整体需求

## 项目是什么

Denpa Jack 是一个 macOS 语音输入工具（个人使用，非商业产品）：

> 按住热键说话 → 松开 → 语音识别（ASR）→ 词典纠错 →（可选）大模型润色 → 写入当前光标位置 / 剪贴板

参考对象是「闪电说」，只取其约 30% 的功能，加上约 10% 的自定义需求；不做会员体系、不做 Agent、不做截图对话等花哨功能。

## 整体需求（产品层）

| 需求 | 具体要求 |
|---|---|
| 输入方式 | 全局热键按住说话，松开结束；Esc 取消**当前**录音（不做"清空队列"这类危险操作） |
| 识别 | 多引擎：豆包（流式）、智谱（文件式）、内置本地网关（mlx-qwen3-asr）、外部 OpenAI 兼容网关 |
| 纠错 | 词典（术语/变体/权重）优先；LLM 润色可选，默认开；带截图上下文时用视觉模型 |
| 交付 | 写入焦点光标（AX 直写，失败回退 Cmd+V 粘贴）；同时写剪贴板；剪贴板恢复可配置 |
| 浮窗 | 录音/转写状态、实时文本、多段队列；按下热键**立即显示**；位置 bottom/top/center；同一时刻只允许一处写浮窗 |
| 历史 | 每段一条记录（原文/结果/引擎/耗时/音频路径），可复制、可重转、可播放 |
| 设置 | 六个页面（通用/历史/词典/语音识别/大模型/关于）；档案式配置（ASR/LLM 各自多档案） |
| 数据目录 | 默认 `~/Library/Application Support/io.github.yangyaofei.denpajack`，可自定义；截图/录音/日志都留档便于复盘 |
| 分发 | 自签证书签名；内置更新（检查+安装，手动确认）；GitHub Release 提供 app/dmg/updater 包 |

## 截图上下文（本轮重点）的具体要求

- 用途：把"当前看到的窗口/屏幕"作为纠错上下文，提升专有名词准确率。
- 目标选择：**焦点窗口（光标所在）优先 → 指针下的窗口 → 指针所在屏**；窗口缺失时回退截屏。
- 排除自身：屏幕截图必须排除本应用自己的窗口（浮窗不入镜）；窗口截图天然不含。
- 与浮窗一致：浮窗放在**同一个目标显示器**上，位置规则不变（默认底部居中）。
- 权限：需要屏幕录制；没有权限只记日志、退回纯文本，不阻塞交付。
- 配置：`detect_active_target` = `off | active_window（默认）| active_display`；旧键忽略、不迁移。

## 非目标（明确不做）

- 多用户、账号体系、云同步。
- 移动端 / Windows / Linux 客户端（本地 ASR 网关可部署到 Linux + NVIDIA，但 APP 只做 macOS）。
- 静默自动更新（只提示，由用户确认安装）。
- 把本地 ASR 引擎嵌进 APP 进程（必须独立进程/子进程，保持 APP 纯 Rust）。

## 关键约束（历史定则，改动时必须遵守）

1. 词典纠错优先于 LLM：能用确定性规则解决的，不交给模型。
2. 一处实现：同一件判断只允许一个实现（本轮"活动目标"就是从两处收敛成一处）。
3. 配置项只在**消费端**使用：探测函数不接收配置，截图端决定截窗口还是截屏。
4. 删除死代码：不再使用的函数/路径要删干净（如截图旧实现、`display_target_at_cursor`）。
5. 版本号六处一致（见 `05-release-and-ops.md`）。
6. 文档与代码同步：`docs/SPEC.md` 是行为契约，改动行为必须同步改它。
